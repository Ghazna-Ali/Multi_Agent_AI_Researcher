# 🔬 ResearchOS AI

A modular multi-agent research application built with:

- CrewAI
- Streamlit
- Groq
- OpenAlex
- Crossref
- arXiv
- Google News RSS

## Agents

1. Research Planner
2. Web Researcher
3. Academic Researcher
4. Evidence Analyst
5. Research Writer

## Models

The application supports multiple Groq models so the user can switch
models when a model reaches its rate limit.

## Deployment

The application is designed for deployment using:

GitHub → Streamlit Community Cloud

## Environment

Python 3.12

## Secret

The application requires:

GROQ_API_KEY
